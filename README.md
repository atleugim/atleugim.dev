# atleugim.dev

My personal website, built with [Astro](https://docs.astro.build/en/getting-started/) and [Tailwind CSS](https://tailwindcss.com/).

## Running on Vercel

View the live site at <https://atleugim.dev>

## Getting Started

### Preview

![image](https://github.com/user-attachments/assets/a4fca17d-2e05-47a2-a08f-42eee86e01b1)

### Install dependencies

```bash
npm install
# or
pnpm install
```

### Start the development server

```bash
npm run dev
# or
pnpm dev
```
